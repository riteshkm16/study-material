## Spring boot

Spring Boot is built on top of the conventional spring framework. So, it provides all the features of spring and is easier to use than spring. Spring Boot is a microservice-based framework and makes a production-ready application in very less time. 

In Spring Boot everything is auto configured. We just need to use proper configuration for utilizing a particular functionality. Spring Boot is very useful if we want to develop REST API.


* The most important feature of the Spring Boot is Autoconfiguration.
    * use @EnableAutoConfiguration or @SpringBootApplication annotations to use autoconfiguration.
* pom.xml file internally handles the required dependencies.
