## Spring Framework

The Spring Framework provides a comprehensive programming and configuration model for modern Java-based enterprise applications - on any kind of deployment platform.


### Features

<li> Core technologies: dependency injection, events, resources, i18n, validation, data binding, type conversion, SpEL, AOP.

<li> Testing: mock objects, TestContext framework, Spring MVC Test, WebTestClient.

<li> Data Access: transactions, DAO support, JDBC, ORM, Marshalling XML.

<li> Spring MVC and Spring WebFlux web frameworks.

<li> Integration: remoting, JMS, JCA, JMX, email, tasks, scheduling, cache and observability.

<li> Languages: Kotlin, Groovy, dynamic languages.
